## 🌍 What is Ploi Cloud?

[Ploi Cloud](https://ploi.cloud) is a next-generation European cloud hosting platform designed to take your applications from code to production in seconds. Your data stays on European soil — always GDPR-compliant, always sovereign.

> Deploy in 12 seconds. Scale automatically. Sleep at night.

---

## ✨ Features

| Category | Details |
|---|---|
| **Framework Support** | Laravel, WordPress, Statamic, Craft CMS, PHP, Node.js |
| **Deployments** | Zero-downtime, git-push deploys, CI/CD ready |
| **Security** | Automatic SSL (Let's Encrypt), end-to-end encryption |
| **Scaling** | Auto-scaling via Kubernetes orchestration |
| **Databases** | PostgreSQL, MySQL, Redis, Valkey, MongoDB with automated backups |
| **Storage** | S3-compatible object storage via MinIO |
| **Monitoring** | Uptime monitoring powered by [Oh Dear](https://ohdear.app), real-time metrics |
| **Infrastructure** | EU-only data centers (Amsterdam, Frankfurt, Madrid — coming soon) |

---

## 🏗️ How It Works

```bash
# 1. Connect your Git repository
# 2. Push your code
git push origin main

# Ploi Cloud handles the rest:
# → Builds your Docker image
# → Deploys to your chosen EU datacenter
# → Provisions SSL, DNS, and monitoring automatically

✓ Live at https://your-app.ams.de.ploi.it  — Deployed in 12 seconds
```
